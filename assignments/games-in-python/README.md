
# 📘 Tarefa: Jogos em Python

## 🎯 Objetivo

Desenvolva jogos interativos em Python praticando manipulação de strings, loops, condicionais, seleção aleatória e entrada de dados do usuário para criar experiências engajantes.

## 📝 Tarefas

### 🛠️ Jogo da Forca

#### Descrição
Construa o clássico jogo de adivinhar palavras onde os jogadores adivinham letras para revelar uma palavra oculta antes de esgotar as tentativas.

#### Requisitos
O programa completo deve:

- Selecionar palavras aleatoriamente de uma lista predefinida usando o módulo `random`.
- Aceitar palpites de letras e mostrar o progresso atual no formato `_ _ _`.
- Rastrear tentativas incorretas restantes e exibir a contagem.
- Encerrar quando a palavra for adivinhada (vitória) ou as tentativas esgotarem (derrota).
- Exibir mensagens de vitória/derrota informativas ao final do jogo.

### 🛠️ Jogo de Adivinhação de Números

#### Descrição
Crie um jogo interativo onde o usuário tenta adivinhar um número secreto gerado aleatoriamente com dicas de "maior" ou "menor".

#### Requisitos
O programa completo deve:

- Gerar um número aleatório entre 1 e 100.
- Solicitar ao usuário que adivinhe o número.
- Fornecer dicas informando se o número secreto é maior ou menor que o palpite.
- Contar o número de tentativas realizadas.
- Exibir uma mensagem de sucesso com o total de tentativas quando o número for acertado.

### 🛠️ Jogo da Memória

#### Descrição
Desenvolva um jogo simples de memória onde pares de elementos devem ser encontrados em uma grade embaralhada.

#### Requisitos
O programa completo deve:

- Criar uma grade com pares de elementos (números, letras ou emojis).
- Embaralhar a posição dos pares aleatoriamente.
- Permitir que o usuário selecione posições para revelar elementos.
- Verificar se dois elementos consecutivos formam um par.
- Rastrear pares encontrados e movimentos realizados.
- Indicar vitória quando todos os pares forem encontrados.
